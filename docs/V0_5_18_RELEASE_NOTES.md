# v0.5.18 · 原生网易云、播放与存储预览版

本次发布包含此前在本地迭代的 Go 原生网易云、管理界面、fnOS 集成及播放存储功能，提供 x86_64 与 ARM64 两种 FPK。

## 主要变化

- 修正旧版 FFmpeg 对元数据残留/无音频输出的截断文件返回成功时，完整性检查可能误放行的问题；校验要求实际解码输出。

- 原生网易云扫码登录、账号私有会话、共享账号与飞牛用户隔离；自建歌单和公共推荐歌单只读展示，支持歌单分页与封面代理缓存。
- 管理界面支持主题跟随、账号管理、音质策略、目录设置、推荐与下载任务管理。
- 增加 App 下载、AAC/HLS 播放、边听边存、滚动缓存、封面与歌词落盘，以及收藏自动落库绑定。
- 补齐原生 EAPI 加密请求体中的登录凭证与设备上下文，使 HTTP Cookie、加密 header 和客户端信息保持一致；此兼容性修正仍需真实 NAS 确认是否解决播放 403。
- 原生和桥接的音频 CDN 请求携带浏览器 User-Agent；API、MusicBox、CDN 的 HTTP 403 分开诊断，逐音质记录脱敏失败类别。
- 转码失败返回失败阶段、错误类别和 FFmpeg 退出码，区分权限、空内容、未知格式、编解码器缺失、损坏音频与 FFmpeg 明确报告的加密错误。
- 完整转码成功后交付 VOD 清单，避免仅拉取一次清单的客户端只拿到开头分片。首次播放需等待整首下载及转码，单次等待上限仍为 30 秒；超时后可在会话回收前重试复用。
- 完善 fnOS 生命周期、Socket 恢复、管理网关验证和旧数据迁移；使用官方 fnpack 生成双架构独立安装包。

## 安装包

- `fnmusic-go-0.5.18-x86.fpk`：x86_64 NAS。
- `fnmusic-go-0.5.18-arm.fpk`：ARM64 NAS。

安装需要 fnOS 1.2.0 或更高版本及官方 `trim.music`。AAC/HLS、MP3 转码与封面嵌入需要设备提供可用 FFmpeg；FPK 不附带 FFmpeg。

## 验证与边界

已完成相关 Go 竞态测试、前端行为测试与类型检查、Linux 双架构构建及 FPK 结构、架构、版本和 SHA-256 校验。本地 FFmpeg 测试覆盖 FLAC 与尾部 moov 的 ALAC/M4A 输入。

本版本仍处于预览阶段。容器及模拟服务验证不代表真实 fnOS 安装、官方客户端和网易云源站兼容性通过。用户反馈的原生模式全曲目 403 尚未在 NAS 上完成修正后复测；请求被拒绝不证明音流加密，本程序未增加解密或绕过账号权益的能力。
