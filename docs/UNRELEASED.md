# 尚未打包的源码改动

以下改动在 v0.5.32 安装包构建之后完成，需重新打包并安装才能在 NAS 生效；下次打包脚本会自动递增版本号。

- QQ 音乐歌曲封面支持 `album.mid` 缺失时使用经过校验的 `album.pmid`，包括 `0030lak94GN5Ad_0` 形式。兼容《虫洞诗》及部分 DJ 版本只有 PMID 的响应，避免空地址导致的 502。
- 缺少 QQ 封面信息时返回内置默认图片；实际网络、图片地址和内容异常保留可区分的诊断类别。
- 搜索按来源并行、分批获取，保留失败前取得的结果，单来源每批最多等待 3 秒；后续批次追加，避免已展示条目改变顺序。
- 显式传入 `page` / `size` 的请求按需获取当前页；当前官方 Web 的歌曲搜索仅传 `q` 且不加载后续页，改为返回候选预算和超时范围内已取得的全部结果，避免停在 50 条。无分页请求仍需等待多批收集，并非前端无限滚动。

验证包括 QQ 封面字段兼容、默认图片与诊断分类、搜索分页/超时/来源中断的回归测试，以及相关竞态检查。实测上述 QQ 歌曲在修复后能通过项目原生适配器取得封面。
