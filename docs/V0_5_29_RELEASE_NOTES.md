# v0.5.29 · 搜索排序优化

本地与所选在线音源按匹配程度分层，同层按来源交错展示，保留来源内部顺序，避免本地结果整批置顶。

- 优先展示歌名与歌手完全匹配，其次为歌名完全匹配、部分匹配、歌手匹配和其他结果。
- 合并候选结果后分页，按用户、所选账号、搜索条件及设置版本隔离缓存 5 分钟；改变页大小仍保持结果顺序。
- 保留不同来源、专辑、时长和 Live／翻唱／伴奏版本，不做跨平台录音合并。
- 搜索失败时原样透传当前请求的官方响应，恢复后可重新获取在线结果。

## 候选范围与等待时间

开启深分页时，每个来源最多获取配置的页数，每页 100 条；关闭时各取一页。总数为候选集过滤后的实际可展示条数。首次搜索需要收集候选页，等待时间可能增加，后续翻页使用缓存。当前仍搜索本地与已授权的所选在线平台，不会同时搜索多个在线账号。

## 验证

Go 全项目测试（含竞态检查）、前端 33 项测试及生产构建通过。新增测试覆盖三来源轮询、匹配优先、版本保留、跨页稳定、改变页大小、账号与条件隔离、设置更新及源站失败恢复。真实 NAS 与源站兼容性仍需安装后验证。
