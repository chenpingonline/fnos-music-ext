# 网易云账号访问模式（v0.3.0-preview）

此功能作用于 fnMusic Go 的 MusicBox HTTP 桥接适配器。每个配置项代表一个**独立的 MusicBox 实例/登录态**，而不是 Go 内部的一套多账号 Cookie。Go 目前不实现网易云扫码、登录或第三方服务的启动；配置前请在不同本机端口启动相互隔离的 MusicBox 服务，且仅接入拥有使用权限的账号。不同账号不应填写相同 HTTP 地址。

## 模式

- **用户隔离（默认开启）**：管理员搜索并选择本机用户名，将每位用户分配到不同网易云账号；同一个账号不能绑定给两个 fnOS 用户。没有绑定的用户只能看到本地音乐。
- **共享账号（隔离关闭）**：管理员在下拉框选择一个已添加的网易云账号，所有经飞牛官方 `/music/api/v1/user/me` 身份验证的用户都可使用该账号的在线能力，**但未验证者仍不能访问**。未选择账号时在线能力关闭。
- 模式切换无需重启；独立模式绑定不会因为切到共享模式而删除。切回独立模式立即恢复原绑定。
- 共享的是在线 MusicBox 实例及其云端登录态，不包括本地飞牛用户数据库。**启用共享即表示允许所有飞牛音乐用户使用该网易云账号的资源和权益，请先取得账号持有者许可。**

## 管理页面

飞牛管理员从桌面 `fnMusic Go` 进入：

1. 先添加账号标识、显示名和 `http://127.0.0.1:<port>` MusicBox 地址。
2. 关闭“账号隔离”开关后，在“共享网易云账号”中选择一个账号即可对全部经验证的飞牛用户启用。
3. 开启“账号隔离”后，搜索并选择飞牛用户名，再选择独立账号并保存。尚未确认音乐身份的分配会显示等待状态；未生效用户仅使用官方本地音乐。
4. 删除一个账号会删除相应绑定，并清空对它的共享选择；MusicBox 实例和登录态不会自动删除。

管理 API（仅可信本地网关管理员请求）：

- `GET /app/fnmusic-go/api/accounts` 获取模式/账户/绑定。
- `POST /app/fnmusic-go/api/accounts` 增加账号；JSON `{ "id":"family", "name":"家庭", "bridge_url":"http://127.0.0.1:8770" }`。
- `DELETE /app/fnmusic-go/api/accounts/{id}` 删除。
- `PUT /app/fnmusic-go/api/accounts/mode` JSON `{ "isolation":false }`。
- `PUT /app/fnmusic-go/api/accounts/shared` JSON `{ "account_id":"family" }`。
- `PUT /app/fnmusic-go/api/accounts/bindings/{fnosGUID}` JSON `{ "account_id":"family" }`；空值解除绑定。

写操作必须来自通过 fnOS 网关身份验证的管理员、携带 `X-FnMusic-Admin: 1` 与 `Content-Type: application/json`。这些 HTTP 头不是独立鉴权凭据；必须配合可信本地 Unix Socket 同伴进程校验，并确保网关剥离外部注入的管理员标记。

配置会原子写入 `${TRIM_PKGVAR}/accounts.json`，目录 0700、文件 0600。不保存网易云密码；原生账号会将登录会话保存在同目录下的 `netease-sessions/`，MusicBox 桥接账号的 Cookie 由各独立实例保存。升级迁移逻辑支持以前单账号的 URL + fnOS GUID 环境变量一次性导入为 `legacy` 账号。

## 已知限制

- 目前账号是独立 MusicBox 实例的映射，尚不支持在 Go 管理端完成扫码登录。
- 登录后的私人歌单、收藏/推荐数据接入官方飞牛音乐的功能尚未迁移完成。
- 仍需真机验证 fnOS 网关管理员头的可信链路、不同设备的手机 App 行为。
- 对在线歌曲仅提供用户有权使用的访问，不能绕过会员、DRM 或平台授权。

## 用户名选择与音乐身份确认（0.5.10）

访问设置改为搜索用户名、选择用户及网易云账号，不再提供手填 GUID 表单。列表读取 NAS 本机 `/etc/passwd` 的普通账户，并用可信统一网关的 `X-Trim-Username` / `X-Trim-Userid` 标注当前用户；无需调用非官方 `user.listUG` 或保存 NAS 登录凭证。域/LDAP 等非本机目录尚未接入。

系统 UID 不等于音乐 GUID。账号分配先按用户名和当时 UID 保存，随后只从官方音乐已经认证的 `/user/me` 响应中提取明确的 `username` / `userName`，核对本机目录后记录其音乐 GUID。没有这些字段时保持“等待音乐身份确认”，不会以昵称、数字 UID 或客户端传入的 Header 猜测关联。需要真实设备确认该版本的音乐接口是否提供相应字段。用户名对应 UID 变化时旧私有分配不会自动应用，管理员需重新保存确认。

共享模式继续对全部已认证音乐用户生效，不依赖用户名到音乐 GUID 的映射。旧版 GUID 绑定保留，页面以可识别用户名或“旧版绑定用户”显示并可解除。身份目录和分配 API 均只开放给管理员；写入保留 CSRF 校验。

新增 `GET /app/fnmusic-go/api/users`、`PUT /app/fnmusic-go/api/accounts/users/{username}`；原有 GUID API 保留兼容但不再作为表单入口。


## 新账号：同窗扫码，验证后保存

新账号在同一弹窗内填写别名、生成二维码和确认扫码状态。浏览器使用 `/api/account-enrollments` 临时登录接口；临时 ID 由服务端生成，草稿不出现在账号列表。取消时丢弃草稿，未完成草稿最多保留 5 分钟；二维码有效期 3 分钟。

原生网易云草稿凭证仅留在内存，扫码授权与登录状态验证都通过后，才保存私有凭证和账号配置。保存失败不向前端报告成功，可以在原草稿重试；配置保存失败会回滚该草稿写入的凭证。MusicBox 桥接的上游登录态仍由其独立实例管理，本应用同样在验证成功后才保存账号配置。

新增账号保存完成后仍沿用既有共享账号或用户分配流程，不自动扩大用户访问范围。既有账号的“歌单”入口继续提供登录状态及歌单管理。
