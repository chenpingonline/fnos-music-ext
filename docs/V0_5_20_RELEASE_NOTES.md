## 安装包

- `fnmusic-go-0.5.20-x86.fpk`：x86_64。
- `fnmusic-go-0.5.20-arm.fpk`：ARM64。

运行要求沿用前版：fnOS 1.2.0+、官方飞牛音乐（trim.music）；相关转码功能需要设备提供 FFmpeg。

本次为界面与文档调整。浏览器示例服务验证不代表真实 NAS、网易云授权或官方客户端播放验收；此前播放 403 等兼容性问题仍需实机确认。
