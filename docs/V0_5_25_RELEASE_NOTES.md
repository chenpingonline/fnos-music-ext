# v0.5.25 · 原生网易云与歌单设置优化

- 仅保留 Go 原生网易云，移除 MusicBox HTTP 桥接、连接方式选择及旧版桥接启动参数；添加账号只需填写别名并使用网易云 App 扫码。
- 在线歌曲按音源生成来源标签：网易云显示 `[网易云]`，不再统一显示 `[music box]`。
- 支持按账号选择需要展示的个人歌单，保留用户隔离和共享账号设置。
- 调整设置页与账号界面，表单标签和控件保持左右排列；优化网易云图标体积，并为带内容哈希的静态资源启用缓存。

## 升级说明

原生账号配置、登录凭证和用户绑定继续使用。若旧配置包含 MusicBox HTTP 桥接账号，请在升级前从旧版管理页移除，再在新版扫码添加。新版检测到旧桥接配置会明确报错，不会自动修改配置或迁移 Cookie。`--netease-url`、`--netease-user-guid` 参数已移除，旧桥接环境变量不再导入账号。

## 安装包

- `fnmusic-go-0.5.25-x86.fpk`：x86_64。
- `fnmusic-go-0.5.25-arm.fpk`：ARM64。
- `FPK-SHA256SUMS`：安装包 SHA-256 校验值。

## 验证

Go 全量测试、前端 31 项测试、前端生产构建、Socket 接管与恢复端到端检查通过。桌面和窄屏下的原生扫码界面及模拟授权保存流程已检查。模拟验证不代表真实网易云账号授权或 NAS 安装验收。
