# v0.5.32 · 搜索中断修复与账号状态显示

- 修复单个来源后续页超时或逐曲探活中断时，将前面已成功取得的结果一起丢弃的问题。网易云与 QQ 音乐继续按相关度分层、同层交错展示。
- 不完整结果在 10 秒冷却后，从第一页重新搜索时可重试失败来源；继续翻页时保留原快照，避免中途改变顺序。完整结果仍缓存 5 分钟。
- 按平台记录搜索失败诊断，便于区分超时和其他源站错误。
- 包含账号名称旁的登录状态：每次进入音源账号页面或手动刷新时检查，网络异常与账号失效分别显示。

已通过相关网关竞态测试，以及账号状态功能的 36 项前端测试、生产构建和桌面／窄屏检查。源站登录失效、没有可播放结果等情况仍可能使某个平台无结果，不能仅凭结果列表判断具体原因。

安装包：`fnmusic-go-0.5.32-x86.fpk`、`fnmusic-go-0.5.32-arm.fpk`。程序、前端及清单版本统一为 0.5.32。
