# v0.5.34 · 官方 Web 快速搜索

- 修复 v0.5.33 仅限制单批 3 秒、多个批次仍可能累计等待 15 秒的问题。
- 按优先速度的选择，官方 Web 仅带 `q` 的搜索每个来源最多扫描前 100 条候选，整个搜索阶段最多等待 3 秒；搜索超时设置更短时遵循设置。返回已取得的结果，可能不完整，也可能超过 50 条。浏览器总耗时还包括身份验证、传输等开销。
- 显式分页客户端仍遵循深分页设置；其缓存与快速搜索隔离，避免快速搜索达到上限后阻断深分页。
- 复用已取得的本地响应，减少重复查询；加入 `Server-Timing` 与 `X-FnMusic-Search-Mode`，便于核对部署版本行为和后端耗时。

已通过相关网关竞态回归测试，覆盖每来源上限、总超时、部分结果保留、超过 50 条、分页隔离及本地请求复用。包含 v0.5.33 的 QQ PMID 封面修复。

安装包在源码目录 `dist/`：`fnmusic-go-0.5.34-x86.fpk`、`fnmusic-go-0.5.34-arm.fpk`。
