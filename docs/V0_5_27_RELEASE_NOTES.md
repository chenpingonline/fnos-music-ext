# v0.5.27 · 工具链安全更新

- 使用 Go 1.27.3 重新编译 x86_64、ARM64 程序，修复 crypto/x509 中间证书信任问题 CVE-2026-111943。
- 前端使用 Node.js 22.23.4 构建，包含 Brotli 解码器 CVE-2026-111497 修复；FPK 不附带 Node.js。
- 构建脚本增加安全版本检查；Go 模块最低版本提升至 1.27.3，并记录推荐工具链版本。

## 升级

安装对应架构的 0.5.27 FPK，并确认应用完成重启。现有账号、登录凭证和用户配置继续使用。仅更新系统 Go 或 Node.js 无法修复旧 FPK 内嵌的 Go 标准库。NAS 系统及官方飞牛音乐的证书库、运行时更新仍需通过各自更新渠道完成。

## 功能更新

- 新增实验性 Go 原生 QQ 音乐：手机 QQ 扫码登录、搜索、歌词、封面、按账号权限取流及自建歌单只读展示。
- 沿用共享账号、用户隔离、缓存、下载及转码流程；阻止跨音源歌曲标识混用，媒体请求不携带账号 Cookie。
- QQ 公共推荐、微信扫码、凭证自动刷新及加密音频解密尚未支持。播放权限与音质取决于服务端账号权益，详见 [QQ 音乐说明](QQ_MUSIC_NATIVE.md)。

真实 NAS 安装及上游账号兼容性仍需在设备上验收。

## 验证结果

- Go 全量测试、前端 33 项测试、前端生产构建通过。
- Socket 接管、Range、管理鉴权、正常退出恢复、SIGKILL 恢复与重启端到端检查通过。
- 工具链版本检查的 8 组边界用例通过。
- 已解包核对双架构 FPK：Go 1.27.3、CGO=0，二进制与构建输出一致，包内无 Node.js，SHA-256 校验通过。
