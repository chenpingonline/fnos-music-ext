# v0.5.31 · 完整合入多音源功能

修正此前打包目录未包含另一工作目录中多音源改动的问题，将完整功能合入主目录并重新构建。

- “播放与搜索”增加搜索来源，可单选或同时选择网易云、QQ 音乐；全部取消时只搜索本地。
- “推荐歌单”增加独立的歌单显示来源设置。
- “访问设置”增加账号组合，可为主账号授权另一个平台的账号；每个平台最多使用一个账号，保留用户隔离。
- 本地、网易云和 QQ 音乐结果按匹配分层，同层来源轮询；每个来源保留内部顺序，合并后缓存并分页。
- 歌曲播放、封面、歌单、收藏、下载和后台任务按歌曲所属平台路由，并在撤销账号组合后立即检查权限。
- 各来源候选页数及首次等待时间沿用 v0.5.29 的限制。单个平台故障时保留其他可用平台结果。

程序、管理界面及 FPK 版本统一为 0.5.31。使用对应架构安装包升级，账号组合需要在访问设置中明确授权。
