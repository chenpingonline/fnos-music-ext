# v0.3.0-preview

本次聚焦网易云账号模式与运行时管理：独立模式（默认）每位 fnOS 用户单独绑定一个 MusicBox 实例；共享模式（隔离关闭）管理员选择一个账号供经过 fnOS 身份认证的全部用户使用。

本次新增：
- Go 内置账号管理器、独立与共享模式开关、用户绑定、账号列表/增删，文件原子持久化；
- 管理 API 与 Vue 3 页面，另提供可运行的不依赖 npm 的原生后备管理页；
- 账号级元数据缓存隔离，异常/匿名请求拒绝共享，MusicBox URL 仅允许本机回环地址；
- 老版单账号环境变量自动导入（首次、未配置账号时）；
- 测试覆盖独立/共享切换、数据持久化、权限校验和网络代理恢复。

**不包含** 网易云扫码登录、Go 原生网易云 API、私人歌单和下载；这些能力仍依赖未来开发。尚未在 fnOS 真机安装验证。不要在生产 NAS 开启此预览版。
