# v0.5.0-preview · Go 原生网易云音乐适配

## 已实现

1. 标准库实现 EAPI AES/MD5 的请求封装以及部分响应解码，客户端固定发往网易云接口域名，不能由普通用户指定任意远端 URL。
2. 新增 `native://netease/<账号ID>` 适配器：搜索/分页、歌曲详情、歌词、音频播放、封面、自建歌单与曲目；音乐内容以授权账号返回的 URL 为准，不绕过 VIP / DRM。保持原先本地 MusicBox HTTP Bridge 兼容模式。
3. 管理台新增原生/桥接选择。原生模式无需 Python、Node 或 Docker，登录态保存于 `accounts.json` 同目录的 `netease-sessions/<账号ID>.json`（0600，目录 0700），删除账户时清除对应本地凭证。
4. 管理 API 保留二维码挑战、状态轮询、私有/共享账号选择。服务端不向浏览器传 Cookie/扫码挑战原始 key。
5. 每次列个人歌单先确认当前账户 UID，只展示 `userId == UID` 的自建歌单；按所选账户命名空间限制虚拟歌单 ID。
6. `go test ./...`、`go test -race ./...`、`go vet ./...`，以及模拟的 FNOS Socket 端到端测试与双架构编译。

## 重要边界

- 目前只用 **模拟 EAPI 服务器** 验证业务逻辑：接口路径、密钥、响应结构随时可能变化；尚未真正登录网易云或在 fnOS 上试用。不可把“纯 Go 已编码”等同于“真机可用”。
- 二维码挑战已实现，但是无内置二维码图像生成，管理台提供原生登录链接供其他设备扫码/打开。
- 原生播放以网易云官方服务对该账户返回的音频链接和权益为准，不会跳过试听、VIP、DRM 或版权限制。
- 当前 Go 核心仍执行 Socket 接管，真实机器上安装与卸载有系统风险；请在单独测试 NAS 上验证，不要直接覆盖现有正在使用的扩展。
- `fnpack` 与 Vue npm 依赖在当前环境不可用；仓库保留内嵌可用的后备管理页及 FPK staging，未生成可验证的 `.fpk`。

## 对照用法

```text
账号模式：原生 Go
账号 ID：home
后台存储的地址：native://netease/home
登录态路径：/var/lib/fnmusic-go/netease-sessions/home.json
```

传统桥接账号无需迁移，可以继续通过 `http://127.0.0.1:8770` 使用；不必同时迁移全部用户。
