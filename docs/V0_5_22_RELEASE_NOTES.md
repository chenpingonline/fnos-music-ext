# v0.5.22 · 简化账号添加与扫码

包含 [v0.5.20 的界面更新](V0_5_20_RELEASE_NOTES.md)，进一步简化账号添加：

- 只需填写账号别名，内部账号标识自动生成，不再要求手动填写或在列表展示。
- 点击“创建并扫码”后自动进入登录面板并生成二维码，无需再打开账号或手动点击生成。
- 二维码生成失败可在已有账号面板重试，不重复添加账号；原有账号及用户绑定继续兼容。

新增自动扫码入口测试，现有及新增 24 项前端测试通过，并通过本地示例服务的浏览器流程验证。示例二维码不代表真实网易云授权验证；fnOS 安装与客户端播放仍需设备验收。

安装包：`fnmusic-go-0.5.22-x86.fpk`（x86_64）、`fnmusic-go-0.5.22-arm.fpk`（ARM64）。
