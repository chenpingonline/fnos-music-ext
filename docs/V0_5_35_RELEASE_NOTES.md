# v0.5.35 · 快速搜索并发查询与结果汇总

- 快速模式在不同音源并行的基础上，同一音源先获取第一页，确认总量后并发获取其余页。一次搜索最多 4 个在线请求，每个音源最多 2 个，避免无界并发。
- 返回结果不受请求完成顺序影响：先按原页序合并并去重，再统一按相关度分层，同层交错展示来源。单页失败、超时仍保留已成功取得的其他页及其他来源结果。
- 保留 v0.5.34 的每来源最多 100 条候选、整个搜索阶段最多 3 秒、复用本地响应及显式分页缓存隔离。
- 显式分页客户端继续按需获取，保持已展示前缀稳定。

网关竞态测试已通过，覆盖并发上限、乱序完成、单页失败后保留后续页、去重、总超时和来源排序。在每页模拟 800 毫秒延迟的测试中，5 页从串行预计 4 秒缩短到约 2.4 秒；真实耗时取决于音源和 NAS 网络。

安装包在源码目录 `dist/`：`fnmusic-go-0.5.35-x86.fpk`、`fnmusic-go-0.5.35-arm.fpk`。
